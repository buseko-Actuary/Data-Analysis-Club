# Data Analysis Club

**University of Lusaka (UNILUS) — Department of Mathematics**
Meets **Fridays, 14:00–16:00**, Computer Lab, Business Block.

Every Friday we take a real, messy dataset and turn it into an answer someone
could act on. This repository is the record of that work: one folder per week,
each with the raw data, the brief we worked from, and the write-up.

## Projects

| Week | Date | Project | Dataset | Skill focus |
|---|---|---|---|---|
| 01 | 2026-09-14 | [Shelter outcomes cleaning](week-01-shelter-outcomes/) | Animal shelter outcomes | Parsing, deduplication, formatting |

## How a project folder is laid out

Each `week-NN-short-name/` folder contains:

- `README.md` — the question, the data, the method, the finding, the caveats
- the **raw** data file, exactly as downloaded, before any cleaning
- screenshots or exports of the cleaned result

## How to read a project

Start with the folder's `README.md`. It states what we were trying to find out
and what we concluded, in plain language. The data file is there so you can
redo the work yourself and disagree with us.
